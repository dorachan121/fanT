## 2. 非機能要件

| 項目 | 状況 |
|---|---|
| 性能（§2） | 24fps 固定。フレームレートが落ちたら、プレビューの美肌とブルームを軽くする（保存はフル品質）。開発ビルドに計測オーバーレイ（P-1） |
| 画質（§3） | プレビュー・保存・編集・スタジオが同じシェーダーと乱数シードを使う |
| オフライン（§4） | AI とコンテンツの追加以外は端末だけで動く |
| セキュリティ（§5） | API キーをアプリに置かない。端末の秘密鍵（サーバーはハッシュだけ保存）、生成回数・登録数・分析イベント送信数（アドレスごと）の制限、サーバー側のクレジット管理（返却も同じトランザクション）、Webhook の共有シークレット、Firestore / Storage はクライアントから一切アクセス不可。App Check は未導入（運用手順 §5） |
| プライバシー（§6） | 顔データは保存も送信もしない。AI に送るのは長辺1024px の縮小版だけで、24時間以内に削除。保存画像に位置情報なし。広告 ID なし |
| 保守性（§8） | カメラと描画のライブラリは `engine/` に限定（lint で強制）。コンテンツはデータ（スキーマで検証）。CI で lint・型・テスト・ビルド・権限を検査 |
| アクセシビリティ（§9） | 主要なボタンに読み上げラベル、タップ領域 48、振動はオフにできる |
| デザイン | パステル・丸ゴシック・ぷにっとした操作感（[05](05-screens.md) の「デザインのトーン」）。部品は `ui/` に集約 |

> **動く写真の注記**: AI-06（見える「AI」マーク）は画像にだけ付けている。動画にマークを焼き込むにはネイティブの映像処理が必要なため、今は Veo が埋め込む見えない透かし（SynthID）に頼っている。リリース前に、動画にもマークを付けるか決める。結果の内容チェックも、画像用の SafeSearch ではなく Veo の安全フィルターに頼っている（入力の写真は SafeSearch で確認する）。

## 3. 実機で確認すること

画面の見た目は [スクリーンショット](../screenshots/README.md)（iOS シミュレーター）で確認できる。シミュレーターではアプリの起動時のクラッシュ（未設定の設定値が空のオブジェクトで渡ること）が見つかり、修正済み。

自動テストでは確かめられない項目です。実機（推奨端末と最低端末）で確認してください。

1. **P-1〜P-5**（[07](07-system-architecture.md) §10）。性能オーバーレイで、美肌・顔検出・キャラを入れた状態の fps を測る
2. **プレビューの向き**: 前面・背面カメラで、日付印字・キャラ・ビネットが正しい位置と向きに出る（フレームの回転をシェーダー側に移している）
3. **前面カメラの顔の位置**: キャラが左右反転せずに顔に重なる（顔検出の座標と鏡像の対応）
4. **保存結果がプレビューと一致する**: 比率・左右反転・光漏れ・粒子・日付・キャラ
5. **音量ボタンの撮影**: iOS 17.2 以上と Android。カメラ以外の画面では音量が普通に変わる
6. **写真アプリへの保存**: 追加だけの許可で、専用アルバムに入るか（入らない場合も保存はされる）
7. **プリ**: 連続撮影中の描画の重さ、撮り直し、台紙の保存
8. **課金**: サンドボックスで年額（トライアル）・買い切り・クレジット・復元。Webhook でクレジットが付き、返金（CANCELLATION）で差し引かれる
9. **AI**: ステージング（`AI_PROVIDER=google`）で、スタイルごとの生成結果の質・生成・キャンセル（返却）・タイムアウト・SafeSearch とモデルのブロック・通報
10. **メモリ**: フル解像度の保存・編集を繰り返してもメモリが増え続けない
11. **メイク・顔の微調整**: リップ・アイシャドウ・眉・カラコンの位置が輪郭に合うか（特に前面カメラの鏡像）、歯を白くで舌まで灰色にならないか、 目・小顔の自然さ（強さ最大でも不自然にならないか）、複数人、顔が動いたときの追従、プレビューの fps への影響
12. **レタッチ**: ニキビ消しのなじみ、背景ぼかしと髪色の境目（髪の毛先・帽子・肌に近い髪色）、脚長・ほっそりで背景がゆがみすぎないか
13. **プリの背景合成**: 髪の毛や指の輪郭の切り抜きの自然さ、複数人、Android で写真の向きとマスクの向きが合っているか、撮影から仕上げまでの待ち時間
14. **ストーリーズ共有**: iOS・Android で Instagram の作成画面が開き、写真と背景色が渡るか。Instagram が入っていないときの案内
15. **フレーム**: チェキ風・デジカメ液晶・推し色の見た目（枠の太さ、液晶の文字の読みやすさ、日付印字との重なり）
16. **見た目と操作感**: 丸ゴシックの読み込み、絵文字の表示、押したときのアニメーションと振動の気持ちよさ、写真の上の文字の読みやすさ、小さい画面での文言の折り返し
18. **動く・立体的なキャラ**: 頭を左右・上下に向けたときにサングラスが顔に付いてくるか（yaw の符号が前面・背面カメラで正しいか）、舞うパーツの速さと数がうるさくないか、fps への影響
20. **動画**: 録画の開始・停止と15秒での自動停止、色の焼き込みがプレビューと同じに見えるか（iOS と Android の LUT の向き）、音声、縦向きの保存、書き出しにかかる時間、写真アプリへの保存と共有
19. **AI けしゴム・高画質化**: ステージングで、なぞった所がきれいに消えるか（マスクの位置ずれがないか）、2倍にした結果の質
17. **アドレスごとの制限**: デプロイした API で、`X-Forwarded-For` の最後の値が接続元のアドレスになっているか（ヘッダーを偽装しても制限を回避できないか）
21. **風景の編集**: 傾き・遠近補正で顔のキャラやメイクがずれないか、段階フィルターの境目の線の位置と向き、自動補正の結果が極端にならないか（夜景・逆光・雪景色）、風景の補正の強さ（くっきり・かすみ除去を最大にしたとき）、風景フィルム4種の色味
22. **背景の差し替え**: 青空・夕焼け・海・星空の背景の見た目、人物の輪郭のなじみ、人が写っていない写真の扱い
23. **AI 風景・ひろげる**（ステージング）: 空だけが置き換わるか、ひろげた余白が自然につながるか（境目、遠近）
